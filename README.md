Project & Task Management System

A simple Project and Task Management System developed using Python, FastAPI, SQLite, and Streamlit.

Features

- User Registration and Login
- Create Projects
- Create Tasks
- Update Task Status
- View Project Details
- SQLite Database
- FastAPI Backend
- Streamlit Frontend

Technologies Used

- Python
- FastAPI
- SQLite
- Streamlit
- REST API

Project Flow

Register → Login → Create Project → Create Task → Update Status → View Project Details → Logout
